# 🧸 웹 기반 인형뽑기 게임 (Web Claw Machine)

Vite와 GitHub Pages를 이용해 배포하고, Supabase를 백엔드로 활용하는 웹 기반 인형뽑기 게임 프로젝트입니다.

> 📋 작업 순서 및 FE/BE 분담은 **[TASKS.md](./TASKS.md)** 를 참고하세요.

---

## 📌 1. 프로젝트 개요 및 사용자 시나리오 (User Scenario)

본 프로젝트는 단순 로그인 후 3가지 모드의 인형뽑기 게임을 즐기고, 수집한 인형을 매각하거나 랭킹 경쟁 및 유저 간 송금을 지원하는 싱글 플레이 중심 웹 서비스입니다.

```text
[초기 진입] 
유저 가입/로그인 (초기 자금 10,000 Gold 부여) 
   │
   ▼
[메인 로비]
├── 보유 코인 확인 (우측 상단)
├── 1. 콜렉터함 (인형 도감 & 수집 현황 확인)
├── 2. 게임 실행 (소형 / 중형 / 대형 싱글 모드)
├── 3. 랭킹 확인 (티어 현황 및 최고 랭커 리더보드)
├── 4. 상점 (인형 판매, 버프 아이템 구매, 자금 송금)
└── 5. 실시간 매칭 (추후 업데이트 예정)
```

## 📋 2. 소프트웨어 요구사항 명세서 (SRS)

### 2.1 회원가입 및 인증 (Auth)
* **[REQ-AUTH-01] 계정 인증**
  * ID / PW 기반 로그인 및 회원가입 기능을 제공합니다.
* **[REQ-AUTH-02] 초기 자금 지급**
  * 계정 신규 등록 시 최초 자금 `10,000 Gold`를 지급합니다.

---

### 2.2 메인 로비 (Main Lobby)
* **[REQ-LOBBY-01] 보유 재화 표시**
  * 화면 우측 상단에 유저의 현재 보유 자금(Gold)을 실시간으로 표시합니다.
* **[REQ-LOBBY-02] 메뉴 내비게이션**
  * `콜렉터함`, `게임 실행`, `랭킹 확인`, `상점`, `실시간 매칭` 5가지 메인 메뉴 진입 버튼을 제공합니다.

---

### 2.3 콜렉터함 (Collection Book)
* **[REQ-COLL-01] 인형 구성**
  * 총 45종의 인형을 지원합니다. (소형 30개 / 중형 10개 / 대형 5개)
* **[REQ-COLL-02] 수집 현황 시각화**
  * 획득한 인형: 컬러 이미지 및 정보 표시
  * 미획득 인형: 마스킹(실루엣/음영) 처리
* **[REQ-COLL-03] 카테고리 필터링**
  * 좌측 상단 필터를 통해 `ALL`, `소형`, `중형`, `대형`별로 조회할 수 있습니다.

---

### 2.4 게임 시스템 (Game Modes)
* **[REQ-GAME-01] 점수 산출**
  * 인형 획득 성공 시 1개당 `+10점`을 가산합니다.
* **[REQ-GAME-02] 모드별 규칙 및 비용**

| 구분 | 소형 인형 뽑기 | 중형 인형 뽑기 | 대형 인형 뽑기 |
| :--- | :--- | :--- | :--- |
| **난이도** | 하 | 중 | 상 |
| **입장 비용** | 1,000 Gold | 2,000 Gold | 3,000 Gold |
| **진행 방식** | 60초 타임어택 | 60초 타임어택 | 타이밍 클릭 (1회성) |
| **게임 메카닉** | 집게 조작 → 인형을 잡고 구멍에 낙하 | 회전하는 집게 → 버튼 클릭 시 상단 바가 집게를 눌러 낙하 | `1.00초` ~ `20.00초` 진행 중 **20.00초**에 맞춰 버튼 누를 시 박스 오픈 |

---

### 2.5 랭킹 및 티어 시스템 (Ranking & Tier)
* **[REQ-RANK-01] 랭킹 모드 선택**
  * 좌측 상단 드롭다운으로 `소형` / `중형` 게임 모드별 랭킹을 선택 조회합니다. (대형 제외)
* **[REQ-RANK-02] 티어 및 승/강등 로직**
  * **티어 단계**: `Bronze` → `Silver` → `Gold` → ... → `Challenger`
  * **승/강등 판정**: 각 티어별 기준 점수 및 판수를 기준으로, 먼저 달성한 조건에 따라 즉시 승급 또는 강등됩니다.
    * *예시 (Silver 기준)*:
      * 승급: 승급 점수(30점 이상) 조건을 **3회** 달성 시 승급
      * 강등: 강등 점수(20점 미만) 조건을 **4회** 달성 시 강등
* **[REQ-RANK-03] 랭킹 화면 구성**
  * 우측 상단: 로그인한 유저 본인의 현재 티어 및 순위 표기
  * 메인 영역: 최고 랭킹(`Challenger`) 유저들의 리더보드 및 차트 시각화

---

### 2.6 상점 시스템 (Shop & Transfer)
* **[REQ-SHOP-01] 인형 판매 (매각)**
  * 보유 중인 인형을 판매하여 Gold로 환전합니다.
  * **판매가**: 소형 `1,000 Gold` / 중형 `3,000 Gold` / 대형 `5,000 Gold`
* **[REQ-SHOP-02] 아이템 구매**
  * 보유 Gold로 인형뽑기 보조 아이템을 구매할 수 있습니다.
  * **아이템 예시**: 집게 압력 강화권(집게 파워 상승), 타임 추가권 등
* **[REQ-SHOP-03] 유저 간 자금 전달 (송금)**
  * 타 유저의 ID를 지정하여 자신이 보유한 Gold를 전달할 수 있습니다.

---

### 2.7 실시간 매칭 시스템 (Real-time Multiplayer - *추후 구현 예정*)
> **Note**: 해당 기능은 최하위 우선순위로, Core Single-player 기능 완성 후 순차 구현됩니다.

* **[REQ-MULTI-01] 친구와 함께하기 (협동 모드)**
  * 소형(2,000 Gold) / 중형(4,000 Gold) 코옵 지원
  * 역할 분담 (유저 A: 스틱 조작 / 유저 B: 버튼 조작) 후 인형 성공 시 두 유저 모두에게 지급
* **[REQ-MULTI-02] 랭킹전 (PVP 모드)**
  * 동일 티어 유저 간 매칭 및 화면 2분할(Split Screen) 실시간 경쟁
